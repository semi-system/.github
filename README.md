# Semi System

**Building open systems. Engineering without boundaries.**

Semi System is an open-source engineering organization focused on building efficient, secure, and lightweight software for modern infrastructure.

We design and develop practical tools, system-level software, and minimal runtime environments with an emphasis on performance, reliability, security, and simplicity.

### What We Build

- **Systems Engineering** — Low-level software, diskless computing, network boot, and infrastructure components.
- **Minimal Containers** — Lightweight, distroless runtime images designed for smaller attack surfaces and efficient deployments.
- **Infrastructure & Automation** — Tools that simplify deployment, operations, and system management.
- **Open-Source Innovation** — Transparent, reusable solutions built for developers, operators, and the community.

### Our Philosophy

**Minimal by design. Efficient by nature. Open by default.**

We believe great software should be simple to deploy, predictable to operate, efficient with resources, and accessible to everyone.

Built with purpose. Shared with the world.
